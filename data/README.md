# Data

This repository does not redistribute the dataset. Download **PreDist, version 2** from Zenodo:

> Roelofs CMA, Guevara Bastidas E, Hugo T, Faulstich S, Cadenbach A. *PreDist dataset – Operational data of district heating substations labelled with faults and maintenance information*, version 2. Zenodo, 2025. https://doi.org/10.5281/zenodo.17522254 (CC BY 4.0)

Save the archive as `data/predist_dataset.zip`, or point the pipeline to another location:

```bash
export PREDIST_ZIP=/path/to/predist_dataset.zip
```

The archive is unpacked automatically into `work/predist/` on the first run.
